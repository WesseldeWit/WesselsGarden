### 31 aug - Kickoff

Woensdag 16 september

Noem 3 Gestaltprincipes op en laat de ander uitleggen wat ze betekenen en doen.
- Nabijheid; wanneer iets bij elkaar staat ziet het er uit als een 
- Gelijkheid; wanneer iets dezelfde vorm of kleur heeft
- Continuïteit; wanneer lijnen of vormen dezelfde kant op gaan zien we het als een.

Een grid biedt ruimte om te spelen (vrijheid), maar tegelijkertijd ook eenheid en structuur (vastigheid). Wat wordt hiermee bedoeld? 
- doordat je iets in een grid zet kan je daarmee overzicht creeeren wat op verschillende grootes het zelfde blijft.
  
Welk principe neem je mee in een laatste iteratie van je ontwerp? 
- Doordat alle woorden op een bepaalde manier gepositioneerd zijn zie je een trap (nabijheid gestalt-principe)
